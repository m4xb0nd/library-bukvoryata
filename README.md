# Букварята — учебный веб-сайт «Библиотека» на Go

Каталог книг, читатели, выдача и возврат. Только стандартная библиотека Go (1.22+), внешних зависимостей нет.

## Запуск

Сайт работает с базой данных **PostgreSQL**. Таблицы и начальные данные (жанры, несколько книг, один читатель) создаются сами при первом запуске из `schema.sql` и `seed.sql`.

**Через Docker (проще всего):**

```bash
docker compose up --build        # сайт: http://localhost:8080
```

**Без Docker:** нужен установленный PostgreSQL и пустая база.

```bash
createdb library                 # или создайте базу library в pgAdmin / Toad
export DATABASE_URL="postgres://postgres:ПАРОЛЬ@localhost:5432/library?sslmode=disable"
export LIBRARY_PASSWORD=ваш_пароль
go run .                         # сайт: http://localhost:8080
```

Переменные окружения: `DATABASE_URL` (подключение к PostgreSQL), `LIBRARY_PASSWORD` (пароль библиотекаря, по умолчанию `admin` — обязательно смените), `LIBRARY_ADDR` (адрес сервера, по умолчанию `:8080`). Подключение можно задать и флагом: `go run . -db "postgres://..."`.

Кодировка базы должна быть UTF-8 (иначе поиск по русским названиям без учёта регистра может не работать).

Чтобы начать с чистого листа, удалите базу (в Docker: `docker compose down -v`) и запустите сайт снова.

## Оформление

Всё оформление лежит в `static/`. Рисунки можно заменить своими, оставив имена файлов:

| Файл | Где используется |
|---|---|
| `static/img/bg.png` | клетчатый фон всего сайта (повторяется плиткой, клетка 8 px) |
| `static/img/книга1.png` | главная, страница ошибки |
| `static/img/книга2.png` | главная, «Ничего не найдено» |
| `static/img/книга3.png` | «О нас», вход библиотекаря |

Стили — в одном файле `static/css/style.css`; он разбит на пронумерованные разделы в порядке страницы (цвета и шрифт, шапка, содержимое, главная, таблицы, формы, кнопки, подвал, телефон). Цвета и шрифт меняются в самом начале файла. Перезапускать сервер после правки css и рисунков не нужно, достаточно обновить страницу (шаблоны из `templates/` читаются при запуске).

Меню: Главная, Книги, О нас; после входа библиотекаря добавляются Читатели и Выдача. Список пунктов — в начале `main.go` (`publicNav`, `adminNav`).

## Структура

| Файл | Назначение |
|---|---|
| `main.go` | сервер, маршруты, вход библиотекаря, отрисовка страниц |
| `store.go` | сущности, бизнес-правила, SQL-запросы к PostgreSQL |
| `templates/` | HTML-шаблоны страниц (`base.html` — общий каркас с панелью) |
| `static/` | стили и рисунки |
| `data.sql` | начальные данные (выполняется один раз) |
| `schema.sql` | модель БД для Toad Data Modeler (PostgreSQL) |
| `docs/analysis.md` | предметная область, требования, бизнес-процессы |

## Доступ

Без входа: главная, каталог, карточка книги, «О библиотеке». Для библиотекаря (ссылка «Вход для библиотекаря»): читатели, выдача и возврат, добавление и удаление книг.

## Правила

Срок выдачи — 14 дней; не более 5 книг на руках; просроченные книги блокируют новую выдачу; одну книгу нельзя выдать дважды одному читателю; книгу, по которой есть записи о выдаче, удалить нельзя.
